# ESI - Campos Adicionales de Producto para Odoo 13

Cinco campos Char compartidos entre plantilla y variantes. Se muestran en formularios, ventanas “Ver más”, búsquedas y como columnas opcionales en las listas.

Los nombres visibles se cambian desde Ajustes por un usuario del grupo estándar Administración/Ajustes. Los datos no se pierden al renombrar las etiquetas.
