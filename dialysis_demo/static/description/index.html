Hemodiálisis - Demo Clínico

Módulo de prueba para registrar una hoja de sesión de hemodiálisis en tres bloques: pre, intra y post-diálisis.

  • Matriz intra-diálisis configurable cada 30 o 60 minutos.
  • Registro de PA, FC, Qb, Qd, presiones, TMP, UF e incidencias.
  • Checklist de insumos obligatorio antes de completar.
  • Base para mapeo futuro con productos e Inventario.

Aviso: prototipo técnico para pruebas; no es un dispositivo médico ni sustituye validación clínica, legal o de seguridad.
