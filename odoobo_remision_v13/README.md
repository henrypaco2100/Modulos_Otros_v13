# ESI - Reportes de Remisión para Odoo 13

Módulo independiente basado únicamente en `stock`. Incluye Nota de Remisión, Entrega de Consignación, Entrega de Materiales, Recepción de Consignación, Devolución de Proveedores y Devolución de Librerías.

La Nota de Remisión incluye PVP, costo unitario e importe total calculado como cantidad por costo.
